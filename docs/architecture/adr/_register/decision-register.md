# Decision Register

The authoritative status list for every architecture decision in this library. Governed by
[ADR-D0-02](../00-decision-programme/ADR-D0-02-adr-identification-lifecycle-supersession.md)
(identification and lifecycle) and
[ADR-D0-03](../00-decision-programme/ADR-D0-03-decision-authority-and-review-board.md)
(who ratifies what).

**Rule:** an ADR's `status` front-matter field and its row here must always agree. Where
they diverge, the ADR file wins and this register is in error — fix the register, not the ADR.
